# Project status — Meta-Harness

Meta-Harness is a LangGraph-native substrate for self-improving
coding-agent harnesses. The system is built, tested and reproducible.
This page is the one-screen summary; the detail lives in
[`CAPABILITIES.md`](CAPABILITIES.md), and the machine-checked state of
every claim lives in [`CAPABILITY_EVIDENCE.md`](CAPABILITY_EVIDENCE.md).

To check any of it yourself, in one command:

```bash
make verify          # everything provable without credentials
```

## The empirical measurement

The measurement pipeline is complete and tested. The canonical
experiment has not yet been run against a live model, so no pass-rate
number is published: those rows report `UNSUPPORTED` in
`CAPABILITY_EVIDENCE.md` rather than being softened or estimated.

One command produces them, and needs only `ANTHROPIC_API_KEY`:

```bash
uv run meta-harness canonical-experiment --dry-run   # plan + cost, spends nothing
uv run meta-harness canonical-experiment             # evolve → select → measure → holdout → verify → report
```

It runs 280 final trials (200 search-set, 80 holdout) and writes a
publishable result directory under `benchmarks/results/`, after which
the CI check that guards this repository promotes those rows to
measured automatically.
